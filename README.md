THIS PROJECT IS UNDER THE NPO BINARYCIRCUITS

WORKS:-                                                                     
 Made to prevent car accidents by alerting the driver to take action by acts of like
 1. Seeing the distance from the car infront, if distance less then ideal, then alert the driver by light display and buzzer. Is distance sensitive, so if distance is very less then will be more alarming then if distance more
 2. If car accelerates very fast, to a point its dangerous like rash driving. Then using the light display and buzzer warn the driver

COMPONENTS:-
 Arduino Nano
 8X8 Matrix Display
 MPU 6050
 Ultra Sonic Sesnor
 Buzzer
 Solid Core Wires
 Jumper Wires
